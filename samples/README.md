# Sample workbook

`myshows-profile-sample.xlsx` is a small, entirely fictional workbook for importer development and demos. It has the official sheet names and headers, nullable ratings and watched dates, duplicate series/movie titles, and multiple statuses. It contains no profile data from a real MyShows account.

`myshows-notes-sample.json` is also synthetic. Its entity ID is a placeholder: XLSX imports create local IDs, so replace the GUID with the matching ID from the current `myshows-chatgpt.json` export before importing the notes file.
