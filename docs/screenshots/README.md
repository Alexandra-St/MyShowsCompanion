# Demo screenshots

These screenshots were captured from a disposable database imported from [`../../samples/myshows-profile-sample.xlsx`](../../samples/myshows-profile-sample.xlsx). All titles and records are fictional.

- `series.png` — Series view.
- `movies.png` — Movies view.
- `ambiguities.png` — import ambiguity details for an episode whose duplicate series title cannot be resolved safely.

The demo database is not included. To recreate the screenshots, copy the sample workbook to a temporary directory and import that copy with the CLI; the importer creates its database beside the workbook. Never use a personal profile export or the personal Application Support database for screenshots.
